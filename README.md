# 😜 Random-jokes Generator

A simple, fun, and interactive web application that fetches and displays random jokes with the click of a button. Designed with a clean, modern user interface.

## 🚀 Live Demo

Check out the live version of the project here:  
[Random-jokes Generator Live](https://bhuvaneswari123457.github.io/Random-joke-generator/)

## ✨ Features

* **Instant Laughter:** Generates a new joke instantly when the "GENERATE A JOKE" button is clicked.
* **Clean UI:** Minimalist card design with an attractive gradient background.
* **Responsive:** Designed to look great on desktop and mobile browsers.

## 🛠️ Tech Stack

This project is built using the core web development stack:

* **HTML5:** For the structure and layout of the web page.
* **CSS3:** For styling the user interface, including the background gradients, card shadows, and button hover effects.
* **JavaScript (Vanilla):** For handling the click events and fetching/displaying the joke data (likely utilizing a third-party Joke API).

## 📂 Getting Started

To run this project locally on your machine, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/bhuvaneswari123457/Random-joke-generator.git]
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd Random-joke-generator
    ```
3.  **Open the application:**
    Simply open the `index.html` file in your preferred web browser. No server setup is required!
